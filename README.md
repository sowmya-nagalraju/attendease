# AttendEase

AttendEase is a classroom attendance management system built using Spring Boot, Java, MySQL, HTML, CSS, and JavaScript.

## Features

- Student management
- Subject management
- Class session management
- Present/Absent attendance marking
- Prevention of duplicate attendance
- Past attendance correction
- Attendance percentage calculation
- Configurable attendance threshold
- Attendance shortage detection
- REST APIs
- Web-based dashboard

## Technologies

- Java 21
- Spring Boot
- Spring Data JPA
- Hibernate
- Maven
- MySQL
- HTML
- CSS
- JavaScript
